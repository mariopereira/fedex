FedexBasicTracking extends AbstractFedexApi
in package
  • mariopereirafedex

FedexBasicTracking.php : 28

Basic Integrated Visibility API: tracks shipments by tracking number, by the other packages of a multiple piece shipment, by reference and by Transportation Control Number, retrieves tracking documents (such as the signature proof of delivery) and sends tracking notifications (track/v1).

Tracking and retrieving documents change nothing in FedEx, so a request that failed because of a timeout, or a busy server, can be repeated (see FedexClient::setRetryPolicy()). sendNotification() sends emails to the recipients it names: it is never repeated by this library, and one that failed after it was sent may have been delivered

trackByTrackingNumbers()

FedexBasicTracking.php : 208

Track shipments by tracking number: up to 30 tracking numbers in one request.

public trackByTrackingNumbers(array<string|int, mixed>|stdClass $request) : stdClass

The request is checked before it is sent: the fields, their types and their allowed values are the ones of schemas/track.json (a field that is not in the schema is an error), the required fields must be present and trackingInfo has from 1 to 30 entries. What the schema cannot express is checked by FedEx. Fields set to null and empty lists are left out. Nothing is changed in FedEx, so the request can be repeated
