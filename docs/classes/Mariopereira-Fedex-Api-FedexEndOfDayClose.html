FedexEndOfDayClose extends AbstractFedexApi
in package
  • mariopereirafedex

FedexEndOfDayClose.php : 29

Ship End of Day Close API: closes the FedEx Ground shipments of the day, which returns the Ground Manifest that has to be printed before the shipments are tendered to FedEx, and reprints the reports of a close (ship/v1/endofday).

The close uploads and closes the shipments in FedEx, so it is never repeated by this library, except when FedEx answers that the token is not valid, which means that nothing was processed. If an exception is thrown after it was sent (a timeout, a network failure), the close may have been done: check it before sending it again. The reprint only returns reports that FedEx already generated, so a reprint that failed because of a timeout, or a busy server, can be repeated (see FedexClient::setRetryPolicy())

FedexEndOfDayClose.php : 123

Close the FedEx Ground shipments of the day. THIS CLOSES THE SHIPMENTS IN FEDEX: it is a real operation.

public closeGround(array<string|int, mixed>|stdClass $request) : stdClass

The request is checked before it is sent: the types and the allowed values of the fields are the ones of schemas/close.json (a field that is not in the schema is sent as it is, and FedEx decides about it; the types are loose, as in the examples of FedEx: a text can be a number or a boolean, a number can be a text that is a number or blank, and a boolean can be the text true or false in any case, or 0 or 1). The schema requires no field: what it cannot express is checked by FedEx. Fields set to null and empty lists are left out. The request is never repeated by this library, except when FedEx answers that the token is not valid, which means that nothing was processed. If an exception is thrown after the request was sent (a timeout, a network failure), the close may have been done: check it before sending the request again
