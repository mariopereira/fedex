definitions()

FedexShipSchemas.php : 104

Get the definitions of all the requests and responses. The names of the definitions, and of their fields, are the ones of schemas/ship.json, with these differences:

public static definitions() : array<string|int, mixed>
  • FullSchema-VerifyShipment, FullSchema-CancelTag and FullSchema-getConfirmedShipmentAsyncResults are named with an underscore instead of the hyphen (the validator does not accept a hyphen in a name);
  • what the file writes inline or as an overlay of another definition ("this definition, but these keys are required") is a definition of its own, named after the definition and the field that contain it (for example ClearanceItemDetail_address or BrokerDetail_broker);
  • CreateTagRequestedShipment lists as required three keys that the file does not define anywhere (shipTimestamp, shippingLabelType and specialServicesRequested): they are accepted as optional values of any type, and are not checked. Its pickupDetail, which the file adds as an overlay, is required.
Return values
array<string|int, mixed>
