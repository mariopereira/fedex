Methods

definitions()  : array<string|int, mixed>
Get the definitions of all the requests and responses. The names of the definitions, and of their fields, are the ones of schemas/track.json, with these differences, all of them decided with the owner: - ReferenceInformation requires shipDateEndDate, and its example writes shipDateEnd, as every other schema does: shipDateEnd is accepted too, as an optional field - AddressVO requires the field addressVerificationId, which the file never defines, so FedEx can never send it: it is accepted as an optional field of any type - DelayDetail.subType (an enum with the values SNOW, TORNADO and "EARTHQUAKE etc") and ServiceCommitMessage.type (an enum with a stray quote in USPS_DELIVERING") are defective in the file: they are checked as text
