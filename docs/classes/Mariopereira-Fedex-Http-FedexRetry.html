FedexRetry
in package
  • mariopereirafedex

FinalYes
FedexRetry.php : 24

Retry with exponential backoff, shared by FedexClient (the API requests) and FedexAuth (the token request). Each of them retries only the failures of its own kind (FedexClientException or FedexAuthException): a failure of the token request that happens inside an API request is left to the token request, so that the attempts of the two are not multiplied.

An operation is repeated while it fails with something that is worth trying again: HTTP 429, 503 or 504, or a request that could not be completed (network failure, timeout, ...). The delay before the attempt n is a random value between 0 and min(maximum delay, base delay * 2^(n-1)). When the failure carries a valid Retry-After header the wait is the longer of the header and that delay, and if the header asks for more than the longest Retry-After that is accepted the retries stop and the failure is thrown. Nothing is retried until set() is called.
