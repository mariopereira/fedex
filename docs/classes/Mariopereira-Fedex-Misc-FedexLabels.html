FedexLabels.php : 23

Helpers for the labels and the other documents that FedEx returns in the response of a shipment: find them, decode them and save them.

FedEx returns each document already in the format that was asked for in labelSpecification.imageType (PDF, PNG, ZPLII, EPL2), encoded as text in the field encodedLabel. Nothing is converted here: decoding gives the bytes of that format. The schema does not state the encoding of the field; it is treated as standard Base64, and anything that is not valid Base64 is refused.
