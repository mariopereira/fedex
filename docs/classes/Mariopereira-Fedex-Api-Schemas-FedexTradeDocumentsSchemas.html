FedexTradeDocumentsSchemas.php : 16

Definitions of the requests and responses of the Trade Documents Upload API operations that FedexTradeDocuments implements, generated from schemas/upload-documents.json and written for SchemaValidator. The multipart requests are checked part by part: the definitions are the ones of their JSON parts (the files are not checked by a definition)

Methods

definitions()  : array<string|int, mixed>
Get the definitions of all the requests and responses. The names of the definitions, and of their fields, are the ones of schemas/upload-documents.json, with these differences: - FullSchema-ImageUploadServiceInputVO_1 and FullSchema-Base64MultiDocumentRequest are named with an underscore instead of the hyphen (the validator does not accept a hyphen in a name) - Document_1 requires rules and workflowName, which the file never defines and its example does not send: they are accepted as optional values of any type (decided with the owner)
