FedexTokenCache
in
  • mariopereirafedex

FedexTokenCache.php : 19

Storage for the access token, so that it can be shared between PHP requests. Implement it on top of any store (a file, APCu, Redis, a database) and give it to FedexAuth::setTokenCache().

What is stored is a credential that FedEx accepts until it expires: keep it where only the application can read it, and do not put it in a log. FedexAuth treats every failure of the cache as a cache miss, so the methods may throw when the store fails.
