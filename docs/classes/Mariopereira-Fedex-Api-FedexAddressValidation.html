FedexAddressValidation.php : 98

Validate and resolve addresses, with the full control of the request.

public resolve(array<string|int, mixed>|stdClass $request) : stdClass

The request is checked before it is sent: the fields, their types and their allowed values are the ones of schemas/address-validation.json (a field that is not in the schema is sent as it is, and FedEx decides about it; the types are loose, as in the examples of FedEx: a text can be a number or a boolean, a number can be a text that is a number or blank, and a boolean can be the text true or false in any case, or 0 or 1), from 1 to 100 addresses are required, each one with its street lines (the city, the state, the postal code and the country code are optional in the schema, as the minimum fields vary among countries, and FedEx checks them), and the date of inEffectAsOfTimestamp must be a valid YYYY-MM-DD date. Fields set to null and empty lists are left out
