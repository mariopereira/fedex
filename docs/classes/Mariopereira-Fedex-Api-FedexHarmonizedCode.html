FedexHarmonizedCode.php : 27

Harmonized System (HS) Code Classification API: suggests the HS codes of commodities, from their description and their destination or origin country (commodity/v2/hscodes). The search is powered by artificial intelligence, and its results are suggestions only.

The operation only asks FedEx and changes nothing, so a request that failed because of a timeout, or a busy server, can be repeated (see FedexClient::setRetryPolicy())

FedexHarmonizedCode.php : 95

Search the HS codes of commodities.

public searchHarmonizedCodes(array<string|int, mixed>|stdClass $request) : stdClass

The request is checked before it is sent: the types, the lengths and the allowed values of the fields are the ones of schemas/harmonized-code.json (a field that is not in the schema is sent as it is, and FedEx decides about it; the types are loose, as in the examples of FedEx: a text can be a number or a boolean, a number can be a text that is a number or blank, and a boolean can be the text true or false in any case, or 0 or 1). At least one commodity is required, and every commodity needs its description and a destination country or an origin country (or both), as the documentation says. What the schema cannot express is checked by FedEx. Fields set to null and empty lists are left out. Nothing is changed in FedEx, so the request can be repeated
