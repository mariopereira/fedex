Interfaces

FedexTokenCache
Storage for the access token, so that it can be shared between PHP requests. Implement it on top of any store (a file, APCu, Redis, a database) and give it to FedexAuth::setTokenCache().
FedexTransport
Sends HTTP requests on behalf of the package. The default implementation is CurlTransport; another one can be supplied to FedexClient and FedexAuth, for example to test without the network

Classes

AbstractFedexApi
Base class of the FedEx API operations: holds the shared settings and creates the HTTP client
FedexAddressValidation
Address Validation API: validates and resolves addresses (address/v1/addresses/resolve)
FedexBasicTracking
Basic Integrated Visibility API: tracks shipments by tracking number, by the other packages of a multiple piece shipment, by reference and by Transportation Control Number, retrieves tracking documents (such as the signature proof of delivery) and sends tracking notifications (track/v1).
FedexConsolidation
Consolidation API: creates, modifies, confirms, retrieves and deletes consolidations, and creates and deletes the shipments of a consolidation (ship/v1/consolidations).
FedexDutyAndTax
Estimated Duty and Tax API: estimates the duties, the taxes and the fees of a shipment, from its commodities, its origin and its destination (dutytax/v1/estimate).
FedexEndOfDayClose
Ship End of Day Close API: closes the FedEx Ground shipments of the day, which returns the Ground Manifest that has to be printed before the shipments are tendered to FedEx, and reprints the reports of a close (ship/v1/endofday).
FedexGlobalTrade
Global Trade API: retrieves the regulatory documents that a shipment needs, and the advisories that apply to it, before it is shipped (globaltrade/v1).
FedexHarmonizedCode
Harmonized System (HS) Code Classification API: suggests the HS codes of commodities, from their description and their destination or origin country (commodity/v2/hscodes). The search is powered by artificial intelligence, and its results are suggestions only.
FedexLocationsSearch
Locations Search API: finds FedEx locations by address, geographic coordinates or phone number (location/v1/locations)
FedexOpenShip
Open Ship API: creates a shipment that stays open while its packages are added, modified or deleted, over several requests, and confirms it when it is complete, which generates its labels; retrieves an open shipment or one of its packages, deletes an open shipment, and gets the results of the operations that FedEx processes asynchronously (ship/v1/openshipments).
FedexPickup
Pickup Request API: checks when a pickup is available, schedules a FedEx Express or Ground pickup, and cancels it (pickup/v1).
FedexPostalCodeValidation
Postal Code Validation API: validates postal codes and service commitments (country/v1/postal/validate)
FedexRateTransitTimes
Rates and Transit Times API: retrieves the rates, and the transit times, of the services that are available for a shipment (rate/v1/rates/quotes).
FedexRegulatory
Regulatory API: stores the regulatory compliance data of products (CPSC certificates of compliance, EU de minimis product identifiers), which shipments can then reference in commodities[].regulatoryDetails[] (regulatory/v1/profiles).
FedexServiceAvailability
Service Availability API: retrieves the services and the transit times, the services and the packaging options, and the special service options that are available for a shipment (availability/v1).
FedexShip
Ship API: creates, validates and cancels shipments, creates and cancels tags, and retrieves the results of asynchronous shipments (ship/v1/shipments).
FedexTradeDocuments
Trade Documents Upload API: uploads the customs documents of an electronic trade documents (ETD) shipment, before or after it is shipped, and the images (letterhead and signature) used in the documents that FedEx generates (schemas/upload-documents.json).
FedexAddressValidationSchemas
Definitions of the request and the response of the Address Validation API operation that FedexAddressValidation implements, taken from schemas/address-validation.json and written for SchemaValidator. CurlTransport
Default transport: sends the requests with cURL
FedexClient
JSON HTTP client for the FedEx APIs: adds the authorization headers and retries once when the token is rejected.
FedexRetry
Retry with exponential backoff, shared by FedexClient (the API requests) and FedexAuth (the token request). Each of them retries only the failures of its own kind (FedexClientException or FedexAuthException): a failure of the token request that happens inside an API request is left to the token request, so that the attempts of the two are not multiplied.
FedexTransportResponse
